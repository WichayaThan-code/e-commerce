# Frontend i18n workflow (ThaiShopFun)

ภาษาต้นฉบับคือ **ไทย** (`fallbackLng: th`) ไฟล์อยู่ที่ `frontend/src/locales/{th,en,zh}/{common,auth,public,merchant,admin}.json`

## เมื่อเพิ่มหน้า / ข้อความใหม่

1. เรียก key ในโค้ด (namespace ตาม `useTranslation`):
   ```tsx
   const { t } = useTranslation("merchant");
   t("catalog.newFeature", "ข้อความภาษาไทยเริ่มต้น");
   ```
   - ร้านค้าสาธารณะ: `usePublicTranslation()` → `tp("shop.view.foo", "…")` (namespace `public`)
2. รัน sync:
   ```bash
   cd frontend
   npm run i18n:extract
   npm run i18n:check
   ```
3. (ถ้ามี API key) แปล en/zh อัตโนมัติ:
   ```bash
   npm run i18n:translate
   ```
   หรือครบวงจร: `npm run i18n:sync`

## สคริปต์

| Script | ความหมาย |
|--------|-----------|
| `i18n:extract` | สแกน `src/**/*.{ts,tsx}` หา `t` / `tp` / `tc` และ `useTranslation` แล้ว **เติม key ที่ยังไม่มี** (ไม่ทับคำแปลเดิม) |
| `i18n:translate` | แปลจาก `th` → `en` และ `zh-CN` เฉพาะช่องว่าง / ยังเป็นภาษาไทย / placeholder |
| `i18n:check` | ตรวจให้ th/en/zh มี key ชุดเดียวกันทุก namespace |
| `i18n:sync` | extract → translate → check |

## ค่า default ภาษาไทยจากโค้ด

ใส่ข้อความไทยเป็นพารามิเตอร์ที่สองของ `t()` หรือ `defaultValue` ใน object — extract จะใช้เติมใน `th/*.json` เมื่อ key ยังไม่มี

## แปลอัตโนมัติ (ไม่ใส่ key ใน repo)

สร้าง `frontend/.env.local` (ถูก gitignore แล้ว):

```env
TRANSLATE_PROVIDER=google
GOOGLE_TRANSLATE_API_KEY=your_key
# หรือ
# TRANSLATE_PROVIDER=deepl
# DEEPL_API_KEY=your_key
```

- `--dry-run` — แสดงรายการที่จะแปล ไม่เรียก API  
  `npm run i18n:translate -- --dry-run`
- `--force` — ทับคำแปล en/zh ที่มีอยู่ (ใช้เมื่อตั้งใจ refresh)

คำที่ห้ามแปลอยู่ใน `frontend/scripts/i18n-glossary.json`  
Key ที่แปลด้วยเครื่องจะบันทึกใน `frontend/scripts/i18n-machine-translated.json` ให้ทีม review

## i18next-cli

ติดตั้งเป็น devDependency แล้ว (`i18next-cli`) — ใช้ config `frontend/i18next.config.ts` สำหรับ `npx i18next-cli status` / `lint`  
**อย่า** ใช้ `i18next-cli extract` ตรงๆ กับไฟล์ locale ปัจจุบัน (จะจัดโครง JSON ใหม่) — ใช้ `npm run i18n:extract` แทน

## Seed สินค้า (merchant catalog)

ข้อความ catalog ใน `merchant.json` อ้างอิงจาก `frontend/scripts/seeds/merchant-catalog.json` — extract จะเติมเฉพาะช่องว่างหรือ placeholder

## แปลข้อมูลในฐานข้อมูล (Backend)

- ตาราง `content_translations` (Flyway `V16`) เก็บคำแปล en/zh ของ **สินค้า**, **หมวดสินค้า**, **ร้าน**
- ผู้ขายกรอกไทย → ระบบคิว `PENDING` แล้วแปลหลัง commit + งาน scheduled ทุก 1 นาที
- ลำดับหน้าร้าน: HUMAN → MACHINE (DONE) → คอลัมน์ `_en`/`_zh` เดิม → ไทย
- ฟอร์มสินค้า: badge สถานะ + `POST .../translations/use-auto` กลับไปใช้แปลเครื่อง
- Backfill (admin): `POST /api/admin/translations/backfill?entityType=PRODUCT|PRODUCT_CATEGORY|SHOP`

ตั้งค่าใน **environment** (ไม่ใส่ใน repo):

```env
TRANSLATION_PROVIDER=google   # หรือ deepl | none
GOOGLE_TRANSLATE_API_KEY=...
DEEPL_API_KEY=...
TRANSLATION_GLOSSARY=ThaiShopFun,SKU,mg,ml   # ไม่บังคับ
```

Frontend ส่ง `Accept-Language` จาก `i18n.language` ทุก API call แล้ว
